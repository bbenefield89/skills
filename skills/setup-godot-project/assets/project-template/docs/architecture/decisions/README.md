# Decision records

<!-- setup-godot-project:decisions:start;version=1 -->
> **Editing this file:** The `setup-godot-project` skill owns the text between the `setup-godot-project:decisions` markers. The skill replaces that text when its template changes, so do not edit it. Add project instructions under [Project rules](#project-rules), below the end marker.

Record each decision that is hard to reverse in its own file in this folder.
Name each file `NNNN-short-title.md`, where `NNNN` is the next free number.

Each record has these sections:

1. **Context**: the problem and the facts at the time.
2. **Decision**: what was decided.
3. **Consequences**: what this makes easier, and what it makes harder.

Do not change the decision in an old record. When a new decision replaces it, write a new record, and add a line to the old record that names the new one.
