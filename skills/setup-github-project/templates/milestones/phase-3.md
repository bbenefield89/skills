**What this phase represents:** Alpha makes the game wide. The team adds each planned feature and system until the game is feature complete. The full game is playable from start to end. Content can be incomplete, and some assets can be placeholders. The team expects defects.

**Work that belongs here**
- New game systems and features, such as progression, rewards, new modes, and new events.
- Extensions of the systems from the Vertical Slice, such as new save data, new menu behavior, and new audio events.
- Structure changes that make these extensions safe, such as a new owner for a rule that a new feature will change.
- First versions of the remaining content, with placeholders where the final asset is not ready.

**Work that does not belong here**
- Proof that the core loop works. That is Prototype work.
- The first quality standard for art, audio, UI, and code. That is Vertical Slice work.
- Final balance, full polish, and performance work on all devices. That is Beta work.
- Store pages, launch builds, and marketing material. That is Release work.

**Exit condition:** All planned features are in the game, and a player can use each feature. The team adds no feature after this phase.
