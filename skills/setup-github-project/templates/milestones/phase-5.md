**What this phase represents:** Release takes the complete game to players. The team makes release candidates, makes sure that each candidate is safe to ship, and publishes the game. The team makes only the changes that are necessary to ship.

**Work that belongs here**
- Release candidate builds and the final sign-off tests on each target platform.
- Corrections for defects that block the launch.
- Store pages, screenshots, trailers, age ratings, and platform submission.
- The version number, credits, legal text, and the launch checklist.
- The plan for support after launch, such as hotfix steps and defect reports from players.

**Work that does not belong here**
- New features, new content, and balance changes.
- Structure changes to code and changes to test tooling.
- Polish that does not correct a launch-blocking defect.
- Features for a subsequent update. Put these features in a new milestone.

**Exit condition:** The game is available to players, and the launch build is stable.
